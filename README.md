# 💕 Love Story - 1 Month Anniversary Website

Trang web kỷ niệm tình yêu hiện đại, lãng mạn và tinh tế với phong cách thiết kế **Glassmorphism**, tông màu pastel ấm áp (Dusty Rose & Champagne Butter), cùng trải nghiệm đa nền tảng tối ưu cho cả máy tính và điện thoại di động (iOS / Android).

---

## ✨ Tính Năng Nổi Bật

- ⏱️ **Live Love Counter**: Đồng hồ đếm thời gian yêu nhau theo thời gian thực (Ngày, Giờ, Phút, Giây).
- 💌 **Bức Thư Tình 3D (Interactive Envelope)**: Phong bì bưu điện vintage mở ra bức thư tình với hiệu ứng pháo hoa giấy pastel (Confetti) và con dấu sáp đỏ.
- ⏳ **Cột Mốc Tình Yêu (Milestone Timeline)**: Dòng thời gian lưu giữ từng kỷ niệm đáng nhớ (ngày đầu gặp gỡ, cái nắm tay đầu tiên,...).
- 📸 **Album Ảnh Polaroid 3D & Lightbox**:
  - Nghiêng 3D theo góc rê chuột/chạm.
  - Hỗ trợ đổi ảnh trực tiếp (tải ảnh từ máy/điện thoại và lưu tự động vào `localStorage`).
  - Xem ảnh phóng to toàn màn hình với Lightbox.
- 🎴 **Thẻ Lý Do Yêu (3D Flip Cards)**: Lật thẻ tương tác khám phá những điều khiến trái tim rung động.
- 🎁 **Hộp Quà Bất Ngờ & Chứng Nhận Tình Yêu**: Bung pháo hoa giấy cùng chứng nhận tình yêu có chữ ký nắn nót.
- 📝 **Bức Tường Lời Nhắn (Love Notes Wall)**: Viết và dán các mẩu giấy ghi chú ngọt ngào, lưu tự động trên trình duyệt.
- 🌓 **Chuyển Đổi Light / Dark Mode**:
  - Giao diện mặc định: **Light Mode** (Hồng phấn & Kem bơ thanh lịch).
  - Giao diện ban đêm: **Dark Mode** (Rượu vang ấm áp & Ánh nến lung linh).
- 🎵 **Giai Điệu Lãng Mạn**: Nhạc nền phát bằng Web Audio API synthesizer nhẹ nhàng, không lo phụ thuộc bản quyền.
- ⚙️ **Tùy Chỉnh Linh Hoạt**: Hỗ trợ modal tùy chỉnh tên cặp đôi, ngày bắt đầu yêu, và lời tựa dễ dàng.
- 📱 **Giao Diện Mobile Hoàn Hảo**: Thanh dock điều hướng đáy kiểu iOS, căn chỉnh kích thước phông chữ chống zoom trên Safari iPhone.

---

## 🛠️ Công Nghệ Sử Dụng

- **HTML5 & CSS3**: Glassmorphism (`backdrop-filter`), CSS Custom Properties (Theme tokens), CSS Grid & Flexbox, CSS 3D Transforms.
- **JavaScript (ES6+)**:
  - Web Audio API (Ambient music synthesis).
  - Canvas Particle Animation (Cánh hoa & trái tim bay lơ lửng).
  - Canvas Confetti (Hiệu ứng pháo hoa giấy).
  - LocalStorage API (Lưu ảnh đại diện, danh sách ghi chú, thiết lập cá nhân).
  - IntersectionObserver (Theo dõi vị trí cuộn cho thanh điều hướng mobile).

## 🚀 Hướng Dẫn Sử Dụng & Triển Khai (GitHub Pages)

### 1. Xem trực tiếp trên máy:
Mở file `index.html` bằng bất kỳ trình duyệt nào (Google Chrome, Microsoft Edge, Safari, Brave...).

### 2. Triển khai miễn phí lên GitHub Pages:
1. Vào repository của bạn trên GitHub: `Settings` > `Pages`.
2. Tại mục **Branch**, chọn `main` (hoặc `master`) và thư mục `/(root)`.
3. Bấm **Save**. Sau 1-2 phút, trang web sẽ có đường link trực tuyến để gửi cho người thương (dạng: `https://kagerzzz.github.io/LoveStory/`).
